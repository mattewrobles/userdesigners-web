El botón que dice "Enviar" convierte menos que el que dice "Obtener mi reporte gratis". La diferencia no es diseño visual — es UX Writing.

## ¿Qué es UX Writing?

Es la disciplina que define cada palabra dentro de un producto digital: botones, mensajes de error, tooltips, onboarding, notificaciones. Cada palabra tiene un propósito: guiar, informar, convertir.

## Principios básicos

- **Claro** — el usuario entiende en 2 segundos
- **Conciso** — menos palabras, más impacto
- **Útil** — cada texto resuelve una duda o guía una acción
- **Consistente** — mismo tono, misma voz en todo el producto

## Dónde aplica

- Botones y CTAs — "Comenzar prueba gratis" vs "Enviar"
- Mensajes de error — "El correo no es válido. ¿Quieres intentar con otro?"
- Estados vacíos — "Aquí aparecerán tus proyectos. Crea el primero."
- Onboarding — cada pantalla debe responder "¿qué gano yo?"

## El impacto

Un buen UX Writing puede aumentar conversiones entre 15% y 30% sin cambiar una sola línea de diseño. Las palabras diseñan la experiencia tanto como los píxeles.
